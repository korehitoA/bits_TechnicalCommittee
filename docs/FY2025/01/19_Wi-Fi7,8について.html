次世代無線通信規格「Wi-Fi 7 / Wi-Fi 8」と
知っておきたい Wi-Fi の基礎知識

近年、無線通信技術は急速に進化しており、「Wi-Fi 6」「Wi-Fi 7」といった規格名を耳にする機会が増えています。 一方で、「結局なにが変わったのか」「自分の環境にどの程度関係があるのか」が分かりにくいという声も多く聞かれます。

本記事では、最新世代である Wi-Fi 7 と、現在策定が進められている Wi-Fi 8 の概要を整理しつつ、 その前提となる Wi-Fi の基礎知識について解説します。

1. Wi-Fi の世代（規格）と特徴

Wi-Fi には「IEEE 802.11◯◯」という正式名称がありますが、一般向けには 「Wi-Fi 5」「Wi-Fi 6」のような世代番号で表現されることが増えています。 数字が大きいほど、一般的には「高速・低遅延・混雑に強い」方向へ進化していると考えて問題ありません。

図1：Wi-Fi 世代ごとの概略比較
世代名 規格名（IEEE） 主な特徴
Wi-Fi 5 802.11ac 5GHz 帯を中心とした高速通信。現在も広く利用されている。
Wi-Fi 6 802.11ax 同時接続数の増加、混雑環境での効率向上。
Wi-Fi 6E 802.11ax（6GHz 拡張） 新たに 6GHz 帯を利用可能になり、混雑を回避しやすくなった。
Wi-Fi 7 802.11be 高速・低遅延・安定性をさらに強化。MLO 等の新機能を搭載。
Wi-Fi 8（予定） 802.11bn AI 活用やさらなる高速化が検討されている次世代規格（策定中）。
※実際の最大速度・機能は機器や環境により異なります。ここでは特徴のイメージを記載しています。

2. Wi-Fi の周波数帯とその特徴

Wi-Fi では主に 2.4GHz 帯、5GHz 帯、6GHz 帯 の 3 種類の周波数帯が使われます。 それぞれ「届きやすさ」「速度」「混雑しやすさ」が異なります。

図2：周波数帯ごとのイメージ
2.4GHz 帯（遠距離・障害物に強い / 混雑しやすい）
5GHz 帯（高速・中距離 / 一般的な動画・ゲーム用途に向く）
6GHz 帯（超高速・短距離 / 対応機器は現状限られる）
2.4GHz は「広く届くが混みやすい道路」、5GHz は「バランスの良い都市高速」、 6GHz は「新設された空いている高速道路」のようなイメージです。

それぞれの特徴を整理すると、以下のようになります。

  • 2.4GHz 帯：到達距離は長いが、家電や他の機器との干渉が多く、速度は控えめ。
  • 5GHz 帯：比較的高速で混雑しにくく、現在もっとも一般的な帯域。
  • 6GHz 帯：空きが多く高速だが、届く距離は短く、対応機器もまだ少ない。

3. 通信速度を決める 3 つの要素（ボトルネック）

「Wi-Fi が遅い」と感じたとき、その原因は必ずしも Wi-Fi 規格だけとは限りません。 通信速度は、次の 3 つの要素のうち、もっとも遅い部分（ボトルネック）に左右されます。

図3：通信経路とボトルネックのイメージ
インターネット回線 例：光回線、VDSL、モバイル回線など
ルーター / アクセスポイント 利用している Wi-Fi 規格・性能
端末（PC・スマホ等） 対応している Wi-Fi 規格・アンテナ性能
いずれか 1 箇所でも性能が低いと、全体の速度はそこに制限されます。 例：回線が 100Mbps の場合、Wi-Fi 7 ルーターを導入してもインターネット側は 100Mbps を超えられません。

4. Wi-Fi 7（IEEE 802.11be）の主な特徴

Wi-Fi 7 は、現時点で実用化が進んでいる規格の中で最も高性能な世代です。 主な特徴は以下の通りです。

4-1. マルチリンクオペレーション（MLO）

従来は 2.4GHz / 5GHz / 6GHz のいずれか 1 つを使って通信していましたが、 Wi-Fi 7 の MLO（Multi-Link Operation） では、 複数の周波数帯を同時に利用できるようになります。

  • 混雑している帯域から空いている帯域への自動切り替え
  • 複数の帯域を束ねることによる高スループット・低遅延

4-2. 320MHz の広帯域化

特に 6GHz 帯では、最大 320MHz 幅という非常に広い帯域を利用できます。 これは道路で言えば「車線数が倍になった」ようなもので、 一度に流せるデータ量（理論上の最大速度）が大幅に増加します。

4-3. 4K-QAM による通信効率向上

変調方式として 4096-QAM（4K-QAM） が採用され、同じ電波の中により多くの情報を詰め込めるようになりました。 その結果、実効速度が Wi-Fi 6 と比べてさらに向上します。

5. Wi-Fi 8（IEEE 802.11bn：策定中）の展望

Wi-Fi 8 は現在策定が進められている次世代規格で、商用化は 2030 年前後と予想されています。 詳細仕様は確定していないものの、以下のような方向性が検討されています。

  • AI を活用した電波環境の自動最適化
  • 100Gbps 級のさらなる高速化
  • 遅延の一層の低減（XR/AR、産業用ロボットなどを想定）
  • 6GHz 帯の高度な活用と周波数効率の向上

【補足】Windows 端末で現在接続中の Wi-Fi 規格を確認する方法

Wi-Fi 7 や Wi-Fi 6 の性能を活かすには、「ルーターが対応しているか」だけでなく、 実際に端末がどの規格で接続しているかを確認することも重要です。 ここでは、Windows 端末での確認方法を紹介します。

方法：設定画面から確認する

  1. スタートメニューから 設定 を開く
  2. ネットワークとインターネット → Wi-Fi を選択
  3. 現在接続中の Wi-Fi ネットワーク名をクリック
  4. 表示される プロパティ 画面で「プロトコル」を確認
プロトコル表示と Wi-Fi 世代の対応関係
表示されるプロトコル Wi-Fi 世代
802.11n Wi-Fi 4
802.11ac Wi-Fi 5
802.11ax Wi-Fi 6 / Wi-Fi 6E
802.11be Wi-Fi 7
ポイント：
ルーターが高性能でも、端末側の対応状況や電波環境によっては古い規格で接続されることがあります。 体感速度に違和感がある場合は、まずここを確認してみましょう。

6. まとめ

Wi-Fi 7 / 8 は単なる「速度アップ」にとどまらず、低遅延・安定性・効率の観点からも大きな進化が期待される規格です。 一方で、実際の体感速度は回線・ルーター・端末のいずれか 1 つでも性能が不足していると頭打ちになります。

次の記事では、こうした基礎知識を踏まえたうえで、 自宅やオフィスで 「実際にどのように Wi-Fi 環境を整えていくか」 という実践的な観点から解説します。

快適な無線環境をつくるためのポイント
〜自宅・オフィスで今すぐ実践できる改善策〜

オンライン会議やクラウドサービスの利用が増えた現在、Wi-Fi の品質は業務効率に直結します。 「速度が遅い」「接続が不安定」といった課題は、機器の入れ替えだけでなく、 設置場所や設定の見直しなど、比較的簡単な対策で改善できることも少なくありません。

本記事では、前記事の基礎知識を踏まえつつ、自宅・オフィスで実践しやすい改善ポイント を図解とともに紹介します。

1. ルーターの設置場所を見直す

Wi-Fi の電波は「高い位置」「障害物の少ない位置」から発信した方が届きやすくなります。 逆に、床置きや家具の中、金属製ラックの陰などは電波が大きく減衰します。

図4：ルーター設置場所のイメージ

良い例

  • 家・オフィスの中心付近に設置
  • 棚の上など、床から 1m 以上の高さ
  • 周囲に大きな金属や家電が少ない

悪い例

  • 床に直置き
  • テレビボードの中やクローゼットの奥
  • 電子レンジ・冷蔵庫のすぐ横
設置場所を変えるだけで速度や安定性が改善するケースも多く見られます。

2. 間取りを意識した電波の届き方

住居やオフィスの間取りによっても、電波の届きやすさは大きく変わります。 以下は簡易的なイメージ図です。

図5：部屋と電波到達のイメージ（簡略図）
リビング
ルーターをここに設置
◎ 電波強い
書斎
扉 1 枚と壁 1 枚を挟む
○ 通常利用は問題なし
寝室
壁 2 枚＋距離が遠い
△ 速度低下の可能性
ルーターに近い
ルーターから遠い
距離が離れたり、壁の枚数が増えるほど電波強度は低下します。 必要に応じてメッシュ Wi-Fi などの導入も検討しましょう。

3. 周波数帯の使い分け

使用用途や設置場所に応じて、2.4GHz / 5GHz / 6GHz を使い分けることで、 性能を引き出しやすくなります。

図6：用途別・周波数帯の目安
用途 推奨帯域 理由
スマート家電・IoT 機器 2.4GHz広く届く 多少遅くても問題になりにくく、到達距離を優先。
動画視聴・一般的な業務 5GHzバランス型 速度と安定性のバランスが良く、多くの環境で扱いやすい。
オンライン会議・クラウド作業・ゲーム 5GHz / 6GHz高性能 低遅延と高速性を重視。6GHz は対応機器がある場合に有効。

4. メッシュ Wi-Fi の活用

戸建て住宅やフロアが広いオフィスでは、1 台のルーターだけでは電波が届きにくい場合があります。 このようなケースでは、従来型の中継器よりも メッシュ Wi-Fi の導入が有効です。

図7：中継器方式とメッシュ方式の違い（イメージ）

中継器方式

  • 親機 → 中継器 → 端末と段階的に接続
  • 中継器の位置が悪いと速度低下や不安定さが目立つ
  • SSID が複数になる場合もある

メッシュ Wi-Fi

  • 複数のアクセスポイントが連携して「1つのネットワーク」を構成
  • 端末側から見るとシームレスに接続先が切り替わる
  • 広い範囲で安定した通信を実現しやすい

5. 機器の世代とケーブルの確認

Wi-Fi 7 などの新しい規格の性能を活かすには、ルーターだけでなく、 端末や有線部分の機器も対応していることが重要です。

5-1. ルーターと端末の世代

  • ルーターが「Wi-Fi 5」までしか対応していない場合、端末が Wi-Fi 6/7 対応でも性能を出し切れません。
  • 端末側が古い場合も同様で、ルーターを最新化しても効果が限定的になることがあります。
  • 可能であれば、ルーターと主要端末を同じ世代付近にそろえると効果的です。

5-2. LAN ケーブルの種類

有線部分のボトルネックを避けるため、LAN ケーブルの規格も確認しておきます。

図8：LAN ケーブル規格の目安
規格 理論上の最大速度 一般的な用途
Cat5e 1Gbps 通常の家庭・オフィス利用では十分な性能。
Cat6 1Gbps（ノイズに強い） 安定性を重視したい場合に有効。
Cat6a 10Gbps 高速回線やサーバ用途など、高負荷環境向け。
一般的な家庭・オフィス用途では、Cat5e〜Cat6 を目安とすれば問題ないケースが大半です。

6. 回線側がボトルネックの場合

ルーターや設置場所を見直しても改善が見られない場合、 インターネット回線そのものがボトルネックになっている可能性があります。

  • 夜間だけ極端に遅い場合：マンション全体や地域回線の混雑の可能性
  • VDSL 方式（最大 100Mbps 程度）の場合：構造的に高速化が難しい
  • 古い ONU（光回線終端装置）やルーター一体型機器の場合：機器交換で改善する余地あり
ポイント：
「ルーターを高性能なものに替えても速度が変わらない」場合は、 回線契約や建物側の設備を含めて見直す必要があります。

7. まとめ

Wi-Fi 環境の改善は、高価な機器の導入だけでなく、設置場所・周波数帯の使い分け・機器の世代確認 など、 比較的取り組みやすい対策から大きな効果が得られることがあります。

特にリモートワークやオンライン会議が日常的になった現在、安定したネットワーク環境は業務効率に直結します。 本記事の内容が、各自の自宅・オフィスのネットワーク環境を見直すきっかけになれば幸いです。
