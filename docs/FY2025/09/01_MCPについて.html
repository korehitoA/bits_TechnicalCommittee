MCPについて(2025/8版)

OpenAIによるMCP採用の表明

2025年3月27日、OpenAIのCEOであるサム・アルトマンが自身のXアカウントで以下のように投稿しました：

"people love MCP and we are excited to add support across our products. available today in the agents SDK and support for chatgpt desktop app + responses api coming soon!"

この一言は、AI業界に大きな反響を呼び起こしました。競合であるAnthropic社が開発したMCPを、OpenAIが自社製品に採用すると表明したのです。

MCPとは

MCP(Model Context Protocol)は、Anthropic社によって開発されたプロトコルで、「AIのUSB」とも呼ばれる革新的な標準規格です。AIシステムとツール・データを簡単に接続できるようにする仕組みを提供します。

MCPの仕組み

MCPは、AIシステムとツールを効率的に接続するためのクライアント・サーバーモデルを採用しています。AIシステム側にMCPクライアント、ツール側にMCPサーバーを実装し、両者の間で標準化された通信ルールを定めることで、異なるシステムや異なるツールでも同じ方法で利用できるようになります。

MCPサーバーはツールの管理と実行を行いますが、ツールの説明を定義しておくことで、AIシステムからの問い合わせの際にAIが理解できる形式で呼び出しを行えるようになっています。

アクセス権限の管理やツール実行の制限、データの暗号化などの機能もありセキュリティ面も対応しています。

MCPが登場する前のAIの課題

MCPが登場する前のAIシステムは、ツールやデータとの連携をする際、それぞれのツールやデータに対して個別の実装が必要で、AIの持つ本来の力を十分に活用できない状況でした。特にAIエージェントの場合、期待する稼働量に反してできることが限られてしまい、多くの業務で活用が困難でした。

MCPの活用シーン

MCPの登場により、AIシステムの活用範囲が大きく広がりました。例えば社内システムとの連携では、AIが必要な機能を自動的に選択・実行し、データベース操作、ファイル管理、Webアプリケーション制御など、複数の処理を組み合わせた複雑な業務を自動化できます。ユーザーは自然な対話を通じて、曖昧な指示でもAIに業務を依頼することが可能です。

異なるAIモデル間でのコンテキストの共有や、特化型AIと汎用AIの協調動作などのAIとAIとの連携も容易になります。

※AIエージェントとAIエージェントの直接連携はA2Aプロトコルを活用します。

MCPの利用方法

MCPはオープンな標準規格として公開されており、様々な形での導入が可能です。多くのベンダーが公式なMCP対応ライブラリやフレームワークを提供しており、これらを利用することで効率的にMCP対応システムを構築できます。また、MCP仕様に基づいて独自の実装を行うことも可能です。

MCPサーバーの例

MCPサーバーは、AIが各種システムを操作できるように設計されています。重要なのは、これらが対話的に・曖昧な指示でも操作できる点です。

以下に主な種類を紹介します：

データベース系

PostgreSQL MCP, Supabase MCP, SQLite MCPなど

AIがテーブル構造やデータ内容を理解して操作できるようになります。

ブラウザ操作系

Browser MCP, PlayWright MCPなど

AIがブラウザを操作できるようになります。

コミュニケーション系

Slack MCP, Google Calendar MCPなど

AIが内容を理解し送信や管理などができるようになります。

まとめ

MCPの普及により、AIシステムはより実用的で柔軟な業務支援が可能になります。業務でのAIシステム製造時の利用だけでなく開発の場面でもAIエージェント+MCPを活用した効率化が期待できますので、積極的に活用していきましょう。
